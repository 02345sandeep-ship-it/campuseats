# Network Analysis

## Website Analyzed

The website analyzed was:

https://www.iiitvadodara.ac.in/

The browser used was Google Chrome. The DevTools Network panel was opened, "Disable cache" was enabled, and the page was reloaded before analyzing the requests.

## Request Count

The page generated:

**89 requests**

These requests included the main HTML document, stylesheets, images, and other resources required by the page.

## Page Size

The Network panel reported:

- **13.2 MB transferred**
- **13.9 MB resources**

The transferred amount represents the data actually transferred over the network, while the resources value represents the total size of the loaded resources reported by DevTools.

## Slowest Resource

The slowest visible completed resource was:

**logo.png — 3.1 minutes**

The resource size shown in the Network panel was approximately:

**12,243 kB**

This was a significantly large resource compared with most of the other resources visible in the Network panel.

## 3xx/4xx Responses

No 3xx or 4xx HTTP status codes were visible in the Network request list shown during the analysis.

The visible completed requests returned:

**200 OK**

## Cache Setting

The Chrome DevTools Network panel had **Disable cache** enabled during the page reload, as required by the assignment.

## Observation

The page loaded a relatively large number of resources. A total of 89 requests were recorded, with 13.2 MB transferred and 13.9 MB of resources reported. The `logo.png` resource was particularly large and was also the slowest visible completed resource, taking approximately 3.1 minutes.

No 3xx or 4xx responses were visible in the analyzed request list.
