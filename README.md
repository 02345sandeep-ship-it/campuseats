# CampusEats

## CS 543 Web Services

This repository contains the work for CS 543 Web Services Assignment 1.

The assignment focuses on understanding HTTP requests and responses, inspecting network activity using browser developer tools, setting up a Git repository, and describing the CampusEats system.

## Assignment Contents

- `docs/http-log.md` — HTTP request and response experiments using curl.
- `docs/network-analysis.md` — Analysis of website network activity using Chrome DevTools.
- `docs/brief.md` — CampusEats system brief.

## Tools Used

- curl
- Google Chrome DevTools
- Git
- VS Code
